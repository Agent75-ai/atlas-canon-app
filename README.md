# Atlas del Canon — aplicación

Interfaz pública sin datos narrativos incorporados. Carga y guarda el canon directamente en el repositorio privado `Agent75-ai/atlas-canon-data` mediante la API de GitHub.

## Publicación

Activar GitHub Pages desde la rama `main` y la carpeta `/ (root)`.

## Seguridad

La aplicación solicita un token fine-grained limitado al repositorio privado de datos. El token se guarda solo en el navegador del usuario y nunca se incorpora a este repositorio.
